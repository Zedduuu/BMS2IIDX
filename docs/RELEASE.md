# 公测前检查清单

> 每一轮准备发版时从上往下过一遍。打勾的标准是"我亲自做过"，不是"应该没问题"。

## 1. 代码

- [ ] `python -m compileall -q core gui tools`
- [ ] `python tools\check_self_calls.py`（应输出 OK）
- [ ] `python -c "import gui.ui; import gui.services; import core.convert"`
- [ ] `git status` 干净，提交信息说清改了什么

## 2. 功能冒烟（10 分钟）

- [ ] 启动 → 自动检测到游戏 → 显示曲目数/下一个空号正确
- [ ] 转换页：选 BMS 文件夹 → 谱面列出来 → 勾一个 → 加到队列
- [ ] 队列：转换一首 → 进度条走完 → 报告 ok
- [ ] 部署到游戏 → 备份生成 → 重启游戏能看到歌、能玩、BGA 正常
- [ ] 删掉这首歌（回收区）→ 游戏里消失 → 回收区能还原
- [ ] BMS 谱面库：切页不卡 → 双击一首歌 → 回转换页带出文件夹
- [ ] BMS 谱面库：选一首歌 → 「统计 NPS」→ 表格出现均值/峰值/推荐（不再报错）
- [ ] 帮助页：两个日志按钮都能打开
- [ ] 设置：改主题、改成绩库，三处（转换/BMS/设置）同步

## 3. 异常路径（每项都手动点一次）

- [ ] 选一个不是 IIDX 的文件夹 → 提示清楚，不崩
- [ ] 游戏没启动过（没有 log.txt）→ 检测仍可用，模式按文件判断
- [ ] 成绩库路径填错 → 只是成绩列变 `—`，不崩
- [ ] 转换中途关窗口 → 不出现 QThread 崩溃弹窗
- [ ] 故意删掉 `library\logs` 目录 → 重启能自动重建
- [ ] 索引文件改名/损坏 → 提示"索引损坏，已重建"，程序能起来

## 4. 版本与文案

- [ ] 窗口标题 / 关于页版本号一致
- [ ] 帮助页里"已知限制"与实际一致（wmv 覆盖、原版模式实验性、BPM 极端未测）
- [ ] 没有调试残留：`work/` 里的测试文件不随包发布；`print` 调试语句清掉
