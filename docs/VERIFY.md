# 真机验证清单

> 每项都写清「怎么测 / 看什么 / 通过标准」。测完在最后一列填 ✅ / ❌ + 一句现象。
> 建议按顺序测，前面的不过就别急着测后面。

## 环境约定

- 游戏：`G:\Games\Beatmania IIDX 34 Zinrai`（omnimix）
- 曲库：`contents\data_mods\omnimix\info\0\music_omni.bin`
- 转换产物：先转 → 暂存区 → 「部署到游戏」→ 重启游戏
- 出问题看 `library\logs\app.log`
